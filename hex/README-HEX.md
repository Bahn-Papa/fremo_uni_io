# HEX files
The files in this folder are all compiled applications ready to be downloaded to a chip.<br>
There are allways two versions of an application version, one with and one without a bootloader.<br>
The names of such an application version follow these shemata:<br>
<_application name_>**_**<_article number_>**_**<_main version_>**_**<_minor version_>**.hex**<br>
<_application name_>**_**<_article number_>**_**<_main version_>**_**<_minor version_>**_with_loconet_bootloader.hex**

For example: **fremo_uni_io_1512_10_1.hex**
| | |
| --- | --- |
| <_application name_> | fremo_uni_io |
| <_article number_> | 1512 |
| <_main version_> | 10 |
| <_minor version_> | 1 |
no bootloader
